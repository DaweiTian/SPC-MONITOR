统计学基础概念

所有数据分析方法的底层基石
基础 均值（Mean / μ）

全部数据的算术平均值，反映数据的集中趋势。在SPC中作为控制图的中心线（CL）。

计算公式
x̄ = (x₁ + x₂ + … + xₙ) / n = Σxᵢ / n
  • x̄：样本均值
  • xᵢ：第 i 个数据点
  • n：数据点总数
💡
项目实例：31108条灭菌乳数据中，蛋白质均值 = 3.32%，脂肪均值 = 3.87%。这两个值分别作为蛋白质和脂肪控制图的中心线。
基础 标准差（Standard Deviation / σ）

衡量数据偏离均值的离散程度。标准差越大，数据波动越剧烈。SPC控制限的宽度由标准差决定。

样本标准差（ddof=1）
s = √[ Σ(xᵢ - x̄)² / (n - 1) ]
总体标准差（ddof=0）
σ = √[ Σ(xᵢ - μ)² / n ]
  • s：样本标准差（平台使用，更保守）
  • σ：总体标准差
  • n - 1：贝塞尔校正，消除样本估计偏差
不同标准差下的数据分布对比
基础 中位数（Median）

将数据从小到大排列后处于正中间的值。不受极端值影响，常与均值对比判断数据偏态。

计算方法
n 为奇数：Median = x(n+1)/2
n 为偶数：Median = (xn/2 + xn/2+1) / 2
基础 四分位数（Q1 / Q2 / Q3）

将数据分为四个等份的三个分割点。Q2 即中位数。四分位数是箱线图和IQR异常检测的基础。

四分位数与箱线图结构
四分位距（IQR）
IQR = Q3 - Q1
异常边界
下界 = Q1 - 1.5 × IQR
上界 = Q3 + 1.5 × IQR
基础 移动极差（Moving Range / MR）

相邻两个数据点之差的绝对值。在I-MR控制图中用于估计短期过程波动，是计算控制限宽度的核心统计量。

计算公式
MRᵢ = |xᵢ - xᵢ₋₁|
平均移动极差
MR̄ = ΣMRᵢ / (n - 1)
💡
为什么用MR而不是标准差？ 当每次只有1个检测值时（单值控制图），无法计算组内标准差。MR利用相邻数据的差异来估计短期波动，是一种被广泛接受的无偏估计方法。
基础 滑动窗口（Sliding Window）

只取最近 N 个数据点进行计算，而非全部历史数据。确保分析结果反映当前过程状态，而非被早期数据稀释。

检测频率建议窗口覆盖时间用途
高频（每小时多个）30~1-2天短期过程稳定性
中频（每天数个）50~1-2周中期趋势
低频（每天1-2个）100~1-2月长期趋势

正态分布与3σ原则

SPC与过程能力的理论根基
核心 正态分布（Normal Distribution）

自然界和生产过程中最常见的连续概率分布，呈"钟形曲线"。液奶检测指标（脂肪、蛋白质等）近似服从正态分布，这是SPC方法适用的前提。

概率密度函数（PDF）
f(x) = (1 / (σ√2π)) × e^[-(x-μ)² / (2σ²)]
  • μ：均值（决定曲线中心位置）
  • σ：标准差（决定曲线宽窄）
  • e：自然底数 ≈ 2.71828
正态分布钟形曲线与概率区间
核心 3σ原则（68-95-99.7法则）

正态分布中，数据落在均值±kσ范围内的概率：

范围概率含义SPC应用
μ ± 1σ68.27%约2/3的数据Nelson规则的C区边界
μ ± 2σ95.45%约95%的数据Nelson规则的B区边界
μ ± 3σ99.73%几乎所有数据控制限 UCL / LCL
✅
核心逻辑：如果过程稳定且服从正态分布，99.73%的数据应落在 μ±3σ 范围内。超出此范围的概率仅0.27%（约千分之三），因此一旦出现超限点，极大概率是过程发生了异常——这就是SPC控制图的理论基础。
核心 控制图区域划分（A/B/C区）

以中心线为基准，将控制图划分为6个等宽区域，用于Nelson规则的判定：

控制图分区示意（以脂肪指标为例）
区域范围距中心线含义
C区（中心区）μ ± 1σ1σ正常波动区域
B区（警戒区）μ ± 1σ ~ μ ± 2σ1~2σ需关注但可接受
A区（行动区）μ ± 2σ ~ μ ± 3σ2~3σ接近失控，需警惕
超限区超出 μ ± 3σ>3σ失控，立即干预

SPC 统计过程控制

Statistical Process Control — 用数据判断过程是否稳定
核心 SPC（统计过程控制）

利用统计方法对生产过程进行实时监控，区分"正常波动"（Common Cause，随机因素导致）和"异常波动"（Special Cause，可追溯因素导致），从而在缺陷发生前预警。

💡
SPC vs 事后检验：传统检验是"检测次品"→发现问题时已经产生损失；SPC是"监控过程"→在趋势偏离初期就预警，避免产生次品。这正是本项目核心价值——"异常发现太晚"的解决方案。
波动类型原因特征应对策略
正常波动随机因素（温度微变、仪器精度等）在控制限内随机分布无需干预
异常波动可追溯因素（原料批次、设备故障等）违反Nelson规则、超出控制限立即排查并纠正
核心 控制限（UCL / CL / LCL）

控制图的三条关键水平线，基于过程自身数据计算（不是规格限），反映过程的自然波动范围。

I图（单值图）控制限 — 基于移动极差
CL = x̄ （均值）
UCL = x̄ + 2.66 × MR̄
LCL = x̄ − 2.66 × MR̄
  • 2.66 = 3 / d₂，其中 d₂=1.128（n=2时的控制图常数），等价于 3σ
  • MR̄：平均移动极差
MR图（移动极差图）控制限
CL = MR̄
UCL = 3.267 × MR̄
LCL = 0
  • 3.267 = D₄（n=2时的控制图常数）
  • LCL = 0：极差不可能为负
易混 规格限 vs 控制限

这是最容易混淆的一组概念，但二者有本质区别：

规格限（Spec Limits）控制限（Control Limits）
来源外部标准（国标/企标）过程自身数据计算
用途判断产品是否合格判断过程是否稳定
符号USL / LSL / TargetUCL / LCL
示例脂肪 ≥ 3.0%（国标要求）UCL=3.99, LCL=3.89（过程实际波动）
关系控制限应在规格限之内，过程才算"有能力"
规格限与控制限的关系（脂肪指标示例）

I-MR 控制图

Individuals & Moving Range Chart — 单值+移动极差双图
核心 I-MR 控制图

由两张图上下排列组成的控制图，适用于每次检测只有1个数据值的场景（液奶单批次单指标检测正是如此）。

I图（单值图）MR图（移动极差图）
纵轴检测值 xᵢ移动极差 MRᵢ = |xᵢ - xᵢ₋₁|
监控目标过程均值是否偏移过程波动是否增大
中心线x̄MR̄
控制限x̄ ± 2.66×MR̄[0, 3.267×MR̄]
I-MR 控制图完整示例（砖纯牛奶·脂肪·最近30个检测点）
参考 控制图常数表

I-MR控制图使用 n=2（移动极差的样本量=2）对应的常数：

常数n=2时的值用途公式
d₂1.128估计标准差σ̂ = MR̄ / d₂
D₃0MR图下控制限系数LCL = D₃ × MR̄
D₄3.267MR图上控制限系数UCL = D₄ × MR̄
E₂ (或 3/d₂)2.660I图控制限系数UCL/LCL = x̄ ± E₂ × MR̄
实例 完整计算示例

以"砖纯牛奶·脂肪"最近5个检测值为例：3.95, 3.92, 3.98, 3.88, 3.93

# 步骤1：计算均值 x̄ = (3.95 + 3.92 + 3.98 + 3.88 + 3.93) / 5 = 3.932 # 步骤2：计算移动极差 MR₁ = |3.95 - 3.92| = 0.03 MR₂ = |3.92 - 3.98| = 0.06 MR₃ = |3.98 - 3.88| = 0.10 MR₄ = |3.88 - 3.93| = 0.05 MR̄ = (0.03 + 0.06 + 0.10 + 0.05) / 4 = 0.06 # 步骤3：计算I图控制限 UCL = 3.932 + 2.66 × 0.06 = 3.932 + 0.1596 = 4.092 LCL = 3.932 - 2.66 × 0.06 = 3.932 - 0.1596 = 3.772 # 步骤4：计算MR图控制限 UCL_MR = 3.267 × 0.06 = 0.196 LCL_MR = 0 # 步骤5：判断 # 所有检测值在 [3.772, 4.092] 内 → 过程受控 # 所有MR值在 [0, 0.196] 内 → 波动正常

Nelson 8条规则

识别控制图上的8种异常模式 — SPC的核心判异规则

Nelson规则由国际质量专家Lloyd S. Nelson提出，基于控制图的A/B/C区划分，识别8种典型的过程异常模式。每条规则对应一种特定的异常原因类型。

⚠️
规则适用前提：数据需近似正态分布，且过程已建立稳定基线（至少20-25个数据点）。窗口大小不足时部分规则无法触发。
CRITICAL 规则1：1个点超出3σ控制限

任何一个数据点落在UCL之上或LCL之下。这是最经典的失控信号，概率仅0.27%。

条件：xᵢ > UCL 或 xᵢ < LCL
即 xᵢ > μ + 3σ 或 xᵢ < μ - 3σ
规则1：超出控制限的红点

可能原因：原料突变、设备故障、操作失误、仪器校准偏移。

CRITICAL 规则2：连续9个点在中心线同一侧

连续9个点全部高于或低于中心线，表明过程均值发生了系统性偏移。

条件：连续9个 xᵢ 全部 > CL 或 全部 < CL
规则2：连续9点偏低（均值下移）

可能原因：原料供应商更换、配方调整、季节性变化、设备磨损导致的系统性偏移。

WARNING 规则3：连续6个点持续递增或递减

连续6个点形成单调上升或单调下降趋势，表明过程存在渐进性漂移。

条件：xᵢ < xᵢ₊₁ < xᵢ₊₂ < … < xᵢ₊₅（连续6点递增）
或：xᵢ > xᵢ₊₁ > xᵢ₊₂ > … > xᵢ₊₅（连续6点递减）
规则3：连续6点递增趋势

可能原因：设备逐渐老化、温度缓慢漂移、试剂效期衰减、滤芯逐步堵塞。

WARNING 规则4：连续14个点交替上下

连续14个点呈锯齿状交替上升下降，表示存在两个交替变化的因素（如两台设备轮流生产、两个操作员交替操作）。

条件：(xᵢ - xᵢ₋₁) × (xᵢ₊₁ - xᵢ) < 0，持续14个点
即每相邻两个差值符号相反
规则4：交替振荡模式
WARNING 规则5：连续3点中有2点在A区或以外（同侧）

连续3个点中，有2个点落在同一侧的A区（2σ~3σ之间）或超出控制限。表示过程均值可能正在偏移。

条件：连续3点中 ≥2 点 > μ + 2σ 或 < μ - 2σ
规则5：3点中2点在上侧A区
WARNING 规则6：连续5点中有4点在B区或以外（同侧）

连续5个点中，有4个点落在同一侧的B区（1σ以外）或更远。比规则5更温和的均值偏移信号。

条件：连续5点中 ≥4 点 > μ + 1σ 或 < μ - 1σ
规则6：5点中4点在上侧B区外
INFO 规则7：连续15个点在C区（中心线附近）

连续15个点全部落在C区（μ±1σ）内。看似"好"实则异常——波动过小不符合统计预期，可能数据造假、测量系统分辨率不足或分层不足。

条件：连续15点全部在 [μ - 1σ, μ + 1σ] 范围内
规则7：15点全部集中在C区（异常地"好"）
⚠️
为什么波动太小也是问题？ 正态分布中15个点全落在C区的概率极低（约0.32%）。如果出现，通常意味着：①测量仪器分辨率不够，数据被"四舍五入"到了少数几个值；②人为筛选了数据；③过程分层不当（混合了不同批次的数据平均化了波动）。
INFO 规则8：连续8点在C区以外（两侧都有）

连续8个点全部不在C区内，且两侧都有。表示过程波动增大，数据过于分散。

条件：连续8点全部在 C区外（即 |xᵢ - μ| > 1σ），且上侧和下侧各至少1点
规则8：8点全部在C区外，波动增大
规则描述严重程度关注重点
R11点超出3σCRITICAL突发异常
R2连续9点同侧CRITICAL均值偏移
R3连续6点递增/递减WARNING渐进漂移
R4连续14点交替WARNING双因素交替
R53点中2点在A区外WARNING早期偏移
R65点中4点在B区外WARNING温和偏移
R715点全在C区INFO波动过小
R88点全在C区外INFO波动增大

Cpk / Cp 过程能力指数

Process Capability Index — 过程能否稳定产出合格品？
核心 Cp（过程能力指数）

衡量过程潜在能力——如果过程均值恰好对准规格中心，过程能达到多好的能力。Cp不考虑均值偏移。

计算公式
Cp = (USL - LSL) / (6σ)
  • USL：规格上限（Upper Spec Limit）
  • LSL：规格下限（Lower Spec Limit）
  • 6σ：过程自然波动范围（±3σ）
💡
直观理解：Cp = 规格宽度 / 过程宽度。Cp=1 表示规格限恰好等于±3σ，过程刚好"卡线"；Cp=2 表示规格宽度是过程宽度的2倍，非常充裕。
核心 Cpk（过程能力指数，考虑偏移）

衡量过程实际能力——考虑了均值偏离规格中心的影响。Cpk ≤ Cp，当均值恰好对准规格中心时 Cpk = Cp。

双边规格
Cpk = min(Cpl, Cpu)
Cpl = (μ - LSL) / (3σ)　← 下限侧能力
Cpu = (USL - μ) / (3σ)　← 上限侧能力
单边规格（只有上限）
Cpk = Cpu = (USL - μ) / (3σ)
单边规格（只有下限）
Cpk = Cpl = (μ - LSL) / (3σ)
Cpk 评级仪表盘与分布示意
核心 Cpk 评级标准
Cpk等级颜色含义建议
≥ 1.67优秀🟢 绿过程能力充足可降低检测频率
1.33 ~ 1.67良好🟢 绿过程能力可接受维持现状
1.00 ~ 1.33尚可🟡 黄过程能力勉强需加强监控
0.67 ~ 1.00不足🔴 红过程能力不足需改进过程
< 0.67严重不足🔴 红过程能力严重不足立即停产排查
⚠️
项目预警阈值：平台设置 Cpk < 1.33 时触发 WARNING 预警。1.33 是行业广泛接受的最低可接受标准，意味着过程至少有4σ的能力（约63 PPM缺陷率）。
易混 Cp 与 Cpk 的关系
Cpk = Cp × (1 - k)
其中 k = 2|μ - Target| / (USL - LSL)，表示均值偏离规格中心的程度
场景CpCpk说明
均值对准中心1.501.50Cpk = Cp，最佳状态
均值轻微偏移1.501.25Cpk < Cp，有改进空间
均值严重偏移1.500.80Cpk远小于Cp，需校准
实例 Cpk 计算示例

以"砖纯牛奶·蛋白质"为例：均值 μ=3.32%，标准差 σ=0.05，规格限 LSL=3.0%，USL=3.6%

# Cp 计算 Cp = (3.6 - 3.0) / (6 × 0.05) = 0.60 / 0.30 = 2.00 # Cpk 计算 Cpl = (3.32 - 3.0) / (3 × 0.05) = 0.32 / 0.15 = 2.13 Cpu = (3.6 - 3.32) / (3 × 0.05) = 0.28 / 0.15 = 1.87 Cpk = min(2.13, 1.87) = 1.87 → 优秀 # PPM 计算（正态分布） P(低于LSL) = Φ((3.0 - 3.32) / 0.05) = Φ(-6.4) ≈ 0.0000001 P(高于USL) = 1 - Φ((3.6 - 3.32) / 0.05) = 1 - Φ(5.6) ≈ 0.00000001 PPM = (P_below + P_above) × 10⁶ ≈ 0.11 PPM

PPM 缺陷率

Parts Per Million — 百万分之一缺陷率
核心 PPM（百万分之缺陷率）

基于正态分布，预测过程产出不合格品的概率，以"每百万个产品中的缺陷数"表示。

计算公式
P_below = Φ((LSL - μ) / σ)　← 低于下限的概率
P_above = 1 - Φ((USL - μ) / σ)　← 高于上限的概率
PPM = (P_below + P_above) × 1,000,000
  • Φ：标准正态分布的累积分布函数（CDF）
  • μ：过程均值
  • σ：过程标准差

Z-Score 标准分数检验

Z-Score — 用标准差倍数衡量异常程度
核心 Z-Score（标准分数）

将每个数据点转换为"偏离均值多少个标准差"的标准化值。|Z|越大，数据点越异常。

计算公式
Z = (x - μ) / σ
  • Z = 0：数据点恰好等于均值
  • |Z| > 2：偏离2个标准差，约95%置信度异常
  • |Z| > 3：偏离3个标准差，约99.7%置信度异常
Z-Score 异常检测示意（阈值 |Z|>2 标黄，|Z|>3 标红）
|Z| 阈值置信度判定平台标记
≤ 2—正常🔵 蓝点
2 ~ 395%轻度异常🟡 黄点
> 399.7%严重异常🔴 红点
⚠️
局限性：Z-Score对极端值敏感——异常值本身会拉偏均值和标准差，导致部分异常被"隐藏"。改进方案是使用修正Z-Score（用中位数和MAD代替均值和标准差）。

IQR 四分位距法

Interquartile Range — 箱线图异常检测原理
核心 IQR（四分位距）

一种非参数异常检测方法，不依赖正态分布假设，对极端值不敏感。通过箱线图的四分位数定义异常边界。

计算步骤
IQR = Q3 - Q1
下界 = Q1 - 1.5 × IQR
上界 = Q3 + 1.5 × IQR
  • Q1：第25百分位数（下四分位数）
  • Q3：第75百分位数（上四分位数）
  • 1.5：标准倍数，可调（3.0为"极端异常"）
IQR 箱线图异常检测示意
💡
Z-Score vs IQR：Z-Score假设数据正态分布，对极端值敏感；IQR不依赖分布假设，更鲁棒。平台同时提供两种方法，用户可对比使用。

EWMA 指数加权移动平均

Exponentially Weighted Moving Average — 对小偏移敏感的异常监控
核心 EWMA（指数加权移动平均）

对历史数据赋予指数递减的权重——越近的数据权重越大。EWMA对均值的小幅缓慢偏移特别敏感，能发现Nelson规则难以捕捉的微小趋势变化。

递推公式
Zᵢ = λ × xᵢ + (1 - λ) × Zᵢ₋₁
控制限
UCL = μ₀ + L × σ × √[λ/(2-λ) × (1 - (1-λ)²ⁱ)]
LCL = μ₀ - L × σ × √[λ/(2-λ) × (1 - (1-λ)²ⁱ)]
  • λ（lambda）：平滑系数，0 < λ ≤ 1。λ越小越敏感（常用0.1~0.2）
  • L：控制限系数（常用2.5~3）
  • μ₀：目标均值（基线）
  • Z₀ = μ₀：初始值
EWMA 对小偏移的敏感性（λ=0.15，均值在第20点偏移0.5σ）
λ值灵敏度适用场景
0.05 ~ 0.10极高检测极微小偏移（高精度要求）
0.15 ~ 0.20高常规使用（推荐）
0.30 ~ 0.50中兼顾灵敏度和稳定性

ARIMA 模型

AutoRegressive Integrated Moving Average — 时间序列预测
核心 ARIMA(p, d, q)

由三个部分组成的时间序列预测模型，是趋势预测模块的核心算法。通过分析历史数据的自相关性和趋势性，预测未来走向。

参数名称含义作用
p自回归阶数（AR）用过去p个值的线性组合预测当前值捕捉周期性/自相关
d差分阶数（I）对数据做d次差分使其平稳消除趋势
q滑动平均阶数（MA）用过去q个误差的线性组合修正预测捕捉随机冲击
ARIMA(p,d,q) 模型表达式
(1 - φ₁B - φ₂B² - … - φₚBᵖ)(1-B)ᵈxₜ = (1 + θ₁B + θ₂B² + … + θqBᵍ)εₜ
  • B：后移算子（Bxₜ = xₜ₋₁）
  • φᵢ：自回归系数
  • θⱼ：滑动平均系数
  • εₜ：白噪声（随机误差）
  • (1-B)ᵈ：d阶差分操作
差分操作（使数据平稳）
一阶差分：Δxₜ = xₜ - xₜ₋₁
二阶差分：Δ²xₜ = Δxₜ - Δxₜ₋₁
差分后数据应围绕零值波动，无明显趋势
ARIMA 预测示例（脂肪含量趋势预测）
💡
参数选择：平台使用自动定阶（AIC/BIC最小化），自动确定最优的(p,d,q)。常见组合：ARIMA(1,1,1)适合有轻微趋势的序列；ARIMA(0,1,1)等价于指数平滑；ARIMA(2,1,2)适合有周期波动的序列。
辅助 AIC / BIC（模型选择准则）

用于在多个候选ARIMA模型中选择最优参数的准则，平衡拟合优度和模型复杂度。值越小越好。

AIC = 2k - 2ln(L)
BIC = k·ln(n) - 2ln(L)
  • k：模型参数个数
  • L：最大似然值
  • n：样本量

Mann-Kendall 趋势检验

非参数趋势检验 — 不需要正态分布假设
核心 Mann-Kendall 检验

一种非参数统计检验方法，用于判断时间序列是否存在单调趋势（上升或下降）。不要求数据正态分布，不受异常值影响，适合检验液奶检测指标的趋势变化。

步骤1：计算S统计量
S = Σᵢ<ⱼ sgn(xⱼ - xᵢ)，其中 i = 1, 2, …, n-1；j = i+1, …, n
sgn(x) = +1 (x>0), 0 (x=0), -1 (x<0)
步骤2：计算方差（n>10时）
Var(S) = [n(n-1)(2n+5) - Σtₖ(tₖ-1)(2tₖ+5)] / 18
tₖ 为第k组相同数据的个数
步骤3：计算Z统计量
S > 0: Z = (S - 1) / √Var(S)
S = 0: Z = 0
S < 0: Z = (S + 1) / √Var(S)
步骤4：判断趋势
|Z| > 1.96 → 显著趋势（α=0.05，95%置信度）
|Z| > 2.58 → 高度显著趋势（α=0.01，99%置信度）
Z值p值结论趋势方向
Z > 1.96< 0.05显著上升趋势📈
Z < -1.96< 0.05显著下降趋势📉
|Z| ≤ 1.96≥ 0.05无显著趋势➡️
💡
Sen斜率：Mann-Kendall检验通常配合Sen斜率估计使用，量化趋势的大小：β = median[(xⱼ - xᵢ)/(j - i)]，表示每期变化的中位数斜率。
辅助 Sen 斜率（趋势幅度）
计算公式
β = median[(xⱼ - xᵢ) / (j - i)]，∀ i < j
β > 0 表示上升趋势，β < 0 表示下降趋势，|β| 表示每期变化量

3σ合规判定

基于规格限的产品合格性判定
核心 3σ合规判定规则

平台合规判定模块的核心逻辑：以规格限为基准，判定每个检测值是否合格。与SPC控制限不同，合规判定使用的是外部标准规定的规格限。

判定逻辑
合规：LSL ≤ x ≤ USL
不合规（超上限）：x > USL
不合规（低于下限）：x < LSL
判定结果条件颜色标记说明
合规LSL ≤ x ≤ USL🟢 绿色检测值在规格范围内
边缘距规格限 ≤ 1σ🟡 黄色接近边界，需关注
不合规x > USL 或 x < LSL🔴 红色超出规格范围
合规判定区间示意（以脂肪为例：LSL=3.0%, USL=5.0%）
核心 规格限（USL / LSL / Target）
符号全称含义来源
USLUpper Specification Limit规格上限国标/企标
LSLLower Specification Limit规格下限国标/企标
TargetTarget Value目标值配方/工艺标准
⚠️
关键区分：规格限是"产品合不合格"的标准（外部），控制限是"过程稳不稳定"的标准（内部）。一个过程可以"稳定但不合格"（控制限在规格限外），也可以"合格但不稳定"（数据在规格限内但违反Nelson规则）。
