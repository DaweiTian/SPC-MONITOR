SPC（统计过程控制）

SPC
定义

SPC（Statistical Process Control）是一种利用统计方法对生产过程进行实时监控的质量管理技术。它通过采集过程数据、绘制控制图、应用判异规则，来判断过程是否处于"统计受控"状态（即仅有普通原因变异，无特殊原因变异）。

核心思想

变异类型含义示例处理方式
普通原因变异过程固有的、随机的、可预期的波动仪器测量误差、原料微小差异无需干预，过程受控
特殊原因变异非随机的、异常的、需排查的波动仪器校准偏移、操作失误、原料批次异常立即排查并消除
SPC 的目标不是消除所有变异，而是区分普通原因和特殊原因变异，仅在出现特殊原因时才干预过程。过度干预（对普通原因变异做出反应）反而会增加变异。

在本平台中的应用

平台对液奶成品检验的关键指标（蛋白质、脂肪、非脂乳固体、酸度等）使用 I-MR 控制图进行实时监控，结合 Nelson 8 条规则自动识别异常模式，实现从"事后检验"到"过程预防"的转变。

I-MR 控制图（单值-移动极差图）

SPC
定义

I-MR 控制图是 SPC 中用于单值数据（每次只取一个观测值）的控制图，由两张子图组成：

  • I 图（Individuals Chart）：绘制每个单值数据点，监控过程均值是否稳定
  • MR 图（Moving Range Chart）：绘制相邻两个数据点之差的绝对值，监控过程波动是否稳定
液奶检验数据通常是每个批次一个检测值（非子组数据），因此选用 I-MR 图而非 X̄-R 图。这是最适用于本项目的控制图类型。

I 图计算逻辑

公式

中心线（CL） = x̄ = (1/n) × Σxᵢ   （所有数据点的均值）

移动极差均值 = M̄R̄ = (1/(n-1)) × Σ|xᵢ - xᵢ₋₁|   （相邻两点差值的绝对值之均值）

控制上限（UCL） = x̄ + 2.66 × M̄R̄

控制下限（LCL） = x̄ - 2.66 × M̄R̄

2.66 的来源：系数 2.66 = 3 / d₂，其中 d₂ 是控制图常数（n=2 时 d₂=1.128），3 代表 3 个标准差。因此 3 / 1.128 ≈ 2.66。用 M̄R̄ / d₂ 来估计标准差，避免了直接用样本标准差的偏差。

MR 图计算逻辑

公式

中心线（CL） = M̄R̄（移动极差均值）

控制上限（UCL） = 3.267 × M̄R̄   （系数 3.267 = D₄，n=2 时）

控制下限（LCL） = 0   （n=2 时 D₃=0，下限为 0）

I-MR 控制图示例（蛋白质检测值，含Nelson规则违规标记）

计算步骤

  1. 收集连续的 n 个单值数据点 x₁, x₂, ..., xₙ
  2. 计算均值 x̄ 作为 I 图中心线
  3. 计算每个相邻差值 |xᵢ - xᵢ₋₁|，共 n-1 个移动极差 MRᵢ
  4. 计算移动极差均值 M̄R̄
  5. 计算 I 图控制限：CL ± 2.66 × M̄R̄
  6. 计算 MR 图控制限：UCL = 3.267 × M̄R̄，LCL = 0
  7. 将数据点和控制限绘制在图上，应用 Nelson 规则检测异常

控制限（UCL / LCL / CL）

SPC
定义

控制限是控制图上用于判断过程是否受控的统计边界线，由历史数据计算得出，与规格限（人为设定的产品标准）完全不同。

符号名称含义计算方式
CL中心线过程均值的估计值x̄（数据均值）
UCL控制上限正常波动的上边界CL + 3σ̂
LCL控制下限正常波动的下边界CL - 3σ̂
控制限 vs 规格限：控制限是过程告诉你的（基于实际数据计算），规格限是标准告诉你的（基于产品要求设定）。一个过程可以"统计受控"（点都在控制限内）但"不满足规格"（超出规格限），反之亦然。
控制限与规格限的关系示意

分区（A/B/C Zone）

控制限之间的区域被等分为 6 个子区域（每 1σ 宽），用于 Nelson 规则判断：

区域范围距中心线
C 区CL ± 1σ0 ~ 1σ
B 区CL ± 1σ ~ ± 2σ1σ ~ 2σ
A 区CL ± 2σ ~ ± 3σ2σ ~ 3σ

Nelson 规则（8 条判异规则）

SPC
定义

Nelson 规则是 SPC 中用于判断控制图上数据点是否呈现异常模式的一组规则，由 Lloyd S. Nelson 提出。共 8 条，每条对应一种特定的非随机模式，提示可能存在特殊原因变异。

规则描述含义严重程度
R11 个点超出 3σ（A 区以外）单点极端偏离CRITICAL
R2连续 9 个点在中心线同一侧过程均值偏移CRITICAL
R3连续 6 个点持续递增或递减存在趋势性变化WARNING
R4连续 14 个点交替上下存在交替模式（如两台设备交替）WARNING
R5连续 3 个点中有 2 个在 A 区或以外（同侧）过程波动增大WARNING
R6连续 5 个点中有 4 个在 B 区或以外（同侧）过程均值缓慢偏移WARNING
R7连续 15 个点在 C 区（中心线附近）变异过小（可能数据造假或分层问题）INFO
R8连续 8 个点在 C 区以外（两侧都有）变异增大，数据分层INFO
规则设计原理：在正态分布下，纯随机数据出现这些模式的概率极低（通常 < 1%）。因此一旦触发，大概率存在特殊原因。例如 R1 的误报率仅 0.27%（3σ 原则）。

3σ 原则（经验法则）

SPC
定义

3σ 原则（又称经验法则或 68-95-99.7 法则）指出：对于近似正态分布的数据，几乎所有数据值（99.73%）都会落在均值 ± 3 个标准差的范围内。

范围包含数据比例排除概率
μ ± 1σ68.27%31.73%
μ ± 2σ95.45%4.55%
μ ± 3σ99.73%0.27%
公式

P(μ - 3σ < X < μ + 3σ) ≈ 0.9973

即：超出 ±3σ 的概率仅 0.27%（单侧 0.135%）

在本平台中，3σ 原则是控制限设定的基础（UCL/LCL = CL ± 3σ），也是合规判定模块的核心逻辑：检测值超出 ±3σ 即判定为"不合规"。

Cpk / Cp / Ppk（过程能力指数）

过程能力
定义

过程能力指数是衡量过程输出满足规格要求能力的量化指标。它回答了一个核心问题："我的过程能否持续生产合格品？"

三大指数对比

指数全称特点是否考虑偏移
Cp过程能力指数仅衡量波动大小（不考虑均值位置）否
Cpk过程能力指数（修正）同时衡量波动和均值偏移是
Ppk过程性能指数与Cpk类似，但用整体标准差（含长期波动）是
Cp 公式（双边规格）

Cp = (USL - LSL) / (6 × σ̂_within)

其中 σ̂_within = M̄R̄ / d₂（组内标准差估计）

Cpk 公式（双边规格）

Cpk = min( (USL - x̄) / (3 × σ̂_within), (x̄ - LSL) / (3 × σ̂_within) )

即取上侧能力 CPU 和下侧能力 CPL 中的较小值

单边规格

仅有 USL（上限）时：Cpk = (USL - x̄) / (3 × σ̂_within)

仅有 LSL（下限）时：Cpk = (x̄ - LSL) / (3 × σ̂_within)

Cp 与 Cpk 的关系：Cp ≥ Cpk 恒成立。当过程均值恰好位于规格中心时 Cp = Cpk；均值偏移越大，Cpk 越小于 Cp。因此 Cpk 是更保守、更实际的指标。

Cpk 评级标准

Cpk < 1.0
不充分
1.0 ≤ Cpk < 1.33
勉强
1.33 ≤ Cpk < 1.67
充分
1.67 ≤ Cpk < 2.0
优秀
Cpk ≥ 2.0
卓越
Cpk 值等级合格率PPM评价
≥ 2.0卓越≈ 99.99994%0.0018六西格玛水平
1.67 ~ 2.0优秀≈ 99.999%0.58远超要求
1.33 ~ 1.67充分≈ 99.99%63满足要求
1.0 ~ 1.33勉强≈ 99.73%2700勉强合格，需关注
< 1.0不充分< 99.73%> 2700不满足，需改进
本平台设定 Cpk < 1.33 触发 WARNING 预警，因为 1.33 是工业界普遍认可的"过程能力充分"最低门槛。

PPM（百万分之缺陷率）

过程能力
定义

PPM（Parts Per Million）表示每百万个产品中的缺陷数。它是过程能力的另一种表达方式，将 Cpk 指数转换为更直观的"废品率"概念。

计算公式

PPM = (P(X < LSL) + P(X > USL)) × 1,000,000

其中 P(X < LSL) = Φ((LSL - μ) / σ)，P(X > USL) = 1 - Φ((USL - μ) / σ)

Φ 为标准正态分布的累积分布函数（CDF）

通过 Cpk 反推 PPM（近似）

当过程居中时：PPM ≈ 2 × (1 - Φ(3 × Cpk)) × 1,000,000

Cpk单侧 PPM双侧 PPM（居中）合格率
0.566,807133,61486.64%
1.01,3502,70099.73%
1.336312699.987%
1.670.571.1499.99989%
2.00.00180.003699.9999996%
在本平台中，PPM 通过 scipy.stats.norm.sf()（生存函数 = 1 - CDF）精确计算，而非使用近似公式，确保结果准确。

Z-Score（标准分数）

异常检测
定义

Z-Score（又称标准分数、Z 分数）衡量一个数据点偏离均值多少个标准差。它将不同量纲的数据转换为统一的无量纲分数，便于比较和异常判断。

公式

Z = (x - μ) / σ

x = 数据点值，μ = 均值，σ = 标准差

异常判定阈值

|Z| 阈值置信度误报率用途
|Z| > 295.5%4.5%宽松筛查
|Z| > 2.598.8%1.2%中等筛查
|Z| > 399.7%0.3%严格筛查（默认）
|Z| > 3.599.95%0.05%极严格
优缺点：Z-Score 计算简单、速度快，但对极端值敏感——异常值本身会拉偏均值和标准差，导致检测灵敏度下降。适用于近似正态分布的数据。
Z-Score 异常检测示意（蛋白质检测值，|Z| > 3 标红）

IQR（四分位距）

异常检测
定义

IQR（Interquartile Range）是第三四分位数（Q3）与第一四分位数（Q1）之差，衡量数据中间 50% 的离散程度。基于 IQR 的异常检测方法不受极端值影响（鲁棒性强）。

计算步骤

Q1 = 第 25 百分位数（下四分位）

Q3 = 第 75 百分位数（上四分位）

IQR = Q3 - Q1

下界 = Q1 - 1.5 × IQR

上界 = Q3 + 1.5 × IQR

超出 [下界, 上界] 的数据点判定为异常

1.5 的来源：在正态分布下，Q1 ≈ μ - 0.6745σ，Q3 ≈ μ + 0.6745σ，IQR ≈ 1.349σ。因此 1.5 × IQR ≈ 2.024σ，即上下界约在 μ ± 2.7σ 处，对应置信度约 99.3%。这与 3σ 原则接近但更鲁棒。
IQR 箱线图异常检测示意
对比Z-ScoreIQR
鲁棒性差（受极端值影响）强（不受极端值影响）
分布假设假设正态分布无分布假设（非参数）
适用场景正态分布数据任意分布数据
计算复杂度O(n)O(n log n)（需排序）

EWMA（指数加权移动平均）

异常检测
定义

EWMA（Exponentially Weighted Moving Average）是一种给予近期数据更大权重的移动平均方法。在异常检测中，EWMA 控制图对小偏移（1~1.5σ）的检测灵敏度高于常规 Shewhart 控制图。

EWMA 统计量

Z₀ = x̄（初始值 = 均值）

Zᵢ = λ × xᵢ + (1 - λ) × Zᵢ₋₁

λ ∈ (0, 1] 为平滑参数（权重因子）

EWMA 控制限

UCL = x̄ + 3 × σ × √(λ/(2-λ) × (1-(1-λ)²ⁱ))

LCL = x̄ - 3 × σ × √(λ/(2-λ) × (1-(1-λ)²ⁱ))

随着 i 增大，控制限趋近于 x̄ ± 3σ√(λ/(2-λ))

λ 值特点适用场景
0.05 ~ 0.1极敏感，权重衰减极慢检测 1σ 级别微小偏移
0.2中等敏感（推荐默认值）检测 1.5σ 级别偏移
0.3 ~ 0.5较低敏感检测 2σ 级别偏移
1.0退化为 Shewhart 图等价于普通 I 图
EWMA vs Shewhart：Shewhart 控制图（I-MR 图）对突变敏感但对渐变不敏感；EWMA 恰好相反，对小偏移的累积非常敏感。两者互补使用效果最佳。
EWMA vs Shewhart 对比（检测 1σ 偏移）

ARIMA 模型（自回归积分移动平均）

趋势预测
定义

ARIMA（AutoRegressive Integrated Moving Average）是时间序列预测中最经典的统计模型，通过组合自回归（AR）、差分（I）和移动平均（MA）三个组件来建模和预测时间序列数据。

三个组件

组件全称含义参数
AR自回归当前值 = 过去值的线性组合p（阶数）
I积分（差分）对数据做差分使其平稳d（差分阶数）
MA移动平均当前值 = 过去误差的线性组合q（阶数）
ARIMA(p, d, q) 模型

Φ(B) (1-B)ᵈ Xₜ = Θ(B) εₜ

其中：

Φ(B) = 1 - φ₁B - φ₂B² - ... - φₚBᵖ   （AR 多项式）

Θ(B) = 1 + θ₁B + θ₂B² + ... + θqBᵍ   （MA 多项式）

B = 后移算子（BXₜ = Xₜ₋₁）

εₜ = 白噪声（零均值随机误差）

参数选择指南

参数含义选择方法
p（AR阶数）用多少个过去值预测当前值PACF（偏自相关函数）截尾
d（差分阶数）差分几次使序列平稳ADF 检验（通常 0~2）
q（MA阶数）用多少个过去误差预测当前值ACF（自相关函数）截尾
本平台使用 statsmodels.tsa.arima.model.ARIMA 实现预测。典型参数组合：ARIMA(1,1,1) 或 ARIMA(2,0,1)，通过 AIC/BIC 准则自动选择最优参数。
ARIMA 预测示例（蛋白质月度均值趋势 + 95%置信区间）

Mann-Kendall 趋势检验

趋势预测
定义

Mann-Kendall 检验是一种非参数趋势检验方法，用于判断时间序列是否存在显著的上升或下降趋势。不需要数据服从正态分布，不受异常值影响，广泛用于环境、水质、气象等领域的趋势分析。

计算步骤

步骤 1：计算 S 统计量

S = Σᵢ₌₁ⁿ⁻¹ Σⱼ₌ᵢ₊₁ⁿ sgn(xⱼ - xᵢ)

其中 sgn(x) = +1 (x>0), 0 (x=0), -1 (x<0)

步骤 2：计算方差（考虑 ties）

Var(S) = [n(n-1)(2n+5) - Σ tₖ(tₖ-1)(2tₖ+5)] / 18

其中 tₖ 为第 k 组 tied（相同值）组的个数

步骤 3：计算 Z 统计量

S > 0 时：Z = (S - 1) / √Var(S)

S = 0 时：Z = 0

S < 0 时：Z = (S + 1) / √Var(S)

步骤 4：计算 Sen's 斜率（趋势速率）

β = median[(xⱼ - xᵢ) / (j - i)], ∀ i < j

β 表示趋势的变化速率（单位/时间步）

判定标准

|Z| 值p 值（双侧）结论
|Z| ≥ 2.576≤ 0.01极显著趋势（***）
|Z| ≥ 1.96≤ 0.05显著趋势（**）
|Z| ≥ 1.645≤ 0.10弱显著趋势（*）
|Z| < 1.645> 0.10无显著趋势
趋势方向条件Sen's 斜率 β
↑ 上升趋势Z > 0 且显著β > 0
↓ 下降趋势Z < 0 且显著β < 0
→ 无趋势不显著β ≈ 0
为什么选择 Mann-Kendall？：液奶检验数据不严格服从正态分布，且存在异常值和季节性波动。Mann-Kendall 作为非参数方法，不受这些因素影响，是分析检验指标长期趋势的理想选择。
Mann-Kendall 趋势检验示例（脂肪含量月度均值，显著下降趋势）

均值（μ / x̄）与标准差（σ / s）

基础统计
定义

均值是数据的算术平均数，反映数据的集中趋势。标准差是数据偏离均值的平均程度，反映数据的离散程度。两者是所有统计分析的基础。

总体均值 μ（理论值）

μ = (1/N) × Σᵢ₌₁ᴺ xᵢ

样本均值 x̄（实际计算）

x̄ = (1/n) × Σᵢ₌₁ⁿ xᵢ

总体标准差 σ

σ = √[ (1/N) × Σᵢ₌₁ᴺ (xᵢ - μ)² ]

样本标准差 s（无偏估计）

s = √[ (1/(n-1)) × Σᵢ₌₁ⁿ (xᵢ - x̄)² ]

为什么除以 n-1 而非 n？：用样本估计总体时，样本均值 x̄ 本身就是从数据中算出的，导致偏差。除以 n-1（Bessel 校正）可以消除这个偏差，得到无偏估计。当 n 很大时，n 和 n-1 的差异可以忽略。

正态分布（高斯分布）

基础统计
定义

正态分布是自然界最常见的连续概率分布，呈"钟形曲线"。它是 SPC 控制图、过程能力分析、Z-Score 等方法的理论基础。中心极限定理保证了：足够多的独立随机因素叠加后，结果近似正态分布。

概率密度函数（PDF）

f(x) = (1 / (σ√2π)) × exp(-(x-μ)² / (2σ²))

μ = 均值（决定位置），σ = 标准差（决定宽度）

累积分布函数（CDF）

F(x) = P(X ≤ x) = Φ((x - μ) / σ)

Φ 为标准正态分布（μ=0, σ=1）的 CDF

区间概率在 SPC 中的对应
μ ± 1σ68.27%C 区
μ ± 2σ95.45%C 区 + B 区
μ ± 3σ99.73%C 区 + B 区 + A 区（控制限内）
μ ± 4σ99.994%—
μ ± 6σ99.9999998%六西格玛目标
正态性假设在本平台中的角色：SPC 控制图和 Cpk 计算假设数据近似正态分布。液奶检验数据（蛋白质、脂肪等理化指标）通常满足这一假设。若数据严重偏离正态分布，需先做 Box-Cox 变换或使用非参数方法。

置信区间（CI）

基础统计
定义

置信区间是对总体参数（如均值）的一个区间估计，表示在给定置信水平下，总体参数落在该区间的概率。在本平台中主要用于 ARIMA 预测的不确定性表达。

均值的置信区间（大样本）

CI = x̄ ± Z_(α/2) × (σ / √n)

常用置信水平与 Z 值：

90% 置信 → Z = 1.645

95% 置信 → Z = 1.96

99% 置信 → Z = 2.576

在 ARIMA 预测图中，95% 置信区间表示："如果模型正确，真实值有 95% 的概率落在这个带状区域内"。区间越宽，预测不确定性越大；随着预测步数增加，区间逐渐变宽。
🪟

滑动窗口（Sliding Window）

平台特有
定义

滑动窗口是本平台在线监控模块的核心策略：不使用全部历史数据，而是只取最近 N 个数据点进行 SPC 分析和 Cpk 计算。窗口随新数据到来而"滑动"——加入新点、淘汰旧点。

为什么用滑动窗口？：① 过程可能随时间漂移，旧数据不代表当前状态；② 减少计算量，保证实时性；③ 避免早期异常数据长期影响分析结果。

窗口大小策略（自适应）
