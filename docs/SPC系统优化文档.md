### 1.3 现有问题诊断

#### 🔴 功能层面

| 问题编号 | 问题描述 | 严重程度 |
|---------|---------|---------|
| F-01 | **无数据可视化**：SPC控制图区域完全空白，未集成任何图表库 | 严重 |
| F-02 | **规格限未配置**：USL/LSL 显示"未配置"，无法计算过程能力 | 严重 |
| F-03 | **控制限未计算**：UCL/LCL/CL 均为空，说明后端SPC计算逻辑未接入 | 严重 |
| F-04 | **无指标预测功能**：当前框架无预测模块，缺少趋势预测和预警预判 | 中等 |
| F-05 | **预警规则单一**：预警列表仅有基础框架，未展示判异规则（如8大判异准则） | 中等 |
| F-06 | **数据管理缺失**：无数据浏览、导出、清洗功能 | 中等 |
| F-07 | **配置管理缺失**：无品项/指标/规格限/采集频率的可视化配置界面 | 中等 |

#### 🟡 架构层面

| 问题编号 | 问题描述 | 严重程度 |

| A-05 | **Rust启动器与Python后端协作机制不明**：进程管理、端口分配、异常重启策略未明确 | 中等 |

### 2.2 后端优化方案

#### 2.2.1 FT1 数据采集模块

```
采集策略优化：
├── 采集频率分级
│   ├── L0: 5分钟（常规监测）
│   ├── L1: 1分钟（预警状态加密采集）
│   └── L2: 30秒（异常确认高频采集）
├── 采集容错
│   ├── 连接超时重试（3次，指数退避）
│   ├── 数据校验（范围检查、类型检查）
│   └── 断点续采（记录最后采集时间戳）
├── 数据缓冲
│   ├── 本地CSV缓冲队列
│   └── 采集失败数据补录
└── 采集日志
    ├── 成功/失败记录
    ├── 采集耗时统计
    └── 异常自动告警
```

#### 2.2.2 SPC 分析引擎

**控制图类型扩展：**

| 控制图类型 | 适用场景 | 数据要求 |
|-----------|---------|---------|
| I-MR（单值-移动极差） | 每次采集1个数据点（当前已规划） | 单值数据 |
| X-bar R（均值-极差） | 子组采集，每组n个样本（2-10） | 子组数据 |
| X-bar S（均值-标准差） | 子组采集，每组n>10 | 子组数据 |
| P图（不合格率） | 离散数据，不合格品率 | 计数数据 |
| NP图（不合格品数） | 固定样本量的不合格品数 | 计数数据 |

**判异规则（Nelson Rules，8条）：**

| 规则 | 描述 | 异常类型 |
|------|------|---------|
| 规则1 | 1点超出3σ控制限 | 突发异常 |
| 规则2 | 连续9点在中心线同侧 | 均值偏移 |
| 规则3 | 连续6点递增或递减 | 趋势异常 |
| 规则4 | 连续14点交替上下 | 数据分层 |
| 规则5 | 连续3点中2点在2σ外 | 中等偏移 |
| 规则6 | 连续5点中4点在1σ外 | 小偏移 |
| 规则7 | 连续15点在1σ内 | 数据异常集中 |
| 规则8 | 连续8点无1点在1σ内 | 数据过度分散 |

**过程能力分析增强：**

```
计算指标：
├── 短期能力：Cp, Cpk（基于组内变差）
├── 长期性能：Pp, Ppk（基于整体变差）
├── 西格玛水平：Sigma Level = 3 × Cpk（短期）
├── 不合格率：PPM（基于正态分布概率）
├── 偏移系数：Ca = (均值-目标值)/(USL-LSL)/2
└── 能力等级评定
    ├── Cpk ≥ 1.67 → 特级（充分）
    ├── 1.33 ≤ Cpk < 1.67 → 一级（充足）
    ├── 1.0 ≤ Cpk < 1.33 → 二级（勉强）
    ├── 0.67 ≤ Cpk < 1.0 → 三级（不足）
    └── Cpk < 0.67 → 四级（严重不足）
```

#### 2.2.3 指标预测模块

```
预测方案：
├── 短期预测（1-2小时）
│   ├── 移动平均（MA）
│   ├── 指数平滑（ETS）
│   └── 线性回归趋势
├── 中期预测（1个班次）
│   ├── ARIMA 时间序列
│   └── 季节性分解
├── 预警预判
│   ├── 趋势外推 → 预测越限时间
│   ├── 控制限逼近速率 → 提前预警
│   └── 过程能力退化检测
└── 预测准确度
    ├── MAPE（平均绝对百分比误差）
    ├── RMSE（均方根误差）
    └── 残差分析
```

#### 2.2.4 预警引擎

```
预警分级：
├── CRITICAL（严重）
│   ├── 数据超出规格限（USL/LSL）
│   ├── 连续3点超出2σ
│   └── 采集中断 > 15分钟
├── WARNING（警告）
│   ├── 数据超出控制限（UCL/LCL）
│   ├── 触发Nelson判异规则
│   └── 过程能力 Cpk < 1.0
├── INFO（提示）
│   ├── 趋势预测即将越限
│   ├── Cpk 下降趋势
│   └── 采集频率切换通知

预警通知：
├── 界面弹窗 + 声音提示
├── 预警列表实时刷新
├── 预警确认/处理流程
└── 历史预警统计分析
```

### 2.4 Rust 启动器优化

## 四、技术要点说明

### 4.1 SPC控制限计算公式

```
单值-移动极差（I-MR）控制图：

I图：
  CL  = X̄（均值）
  UCL = X̄ + 2.66 × MR̄（MR̄为平均移动极差）
  LCL = X̄ - 2.66 × MR̄

MR图：
  CL  = MR̄
  UCL = 3.267 × MR̄
  LCL = 0

其中：
  MRi = |Xi - Xi-1|（移动极差）
  MR̄ = (ΣMRi) / (n-1)（平均移动极差）
```

### 4.2 过程能力计算公式

```
Cp  = (USL - LSL) / (6σ_within)
Cpk = min[(USL - X̄), (X̄ - LSL)] / (3σ_within)
Pp  = (USL - LSL) / (6σ_overall)
Ppk = min[(USL - X̄), (X̄ - LSL)] / (3σ_overall)

Sigma Level = 3 × Cpk
PPM = (1 - Φ(Z)) × 1,000,000

其中：
  σ_within  = MR̄ / 1.128（组内标准差，I-MR图）
  σ_overall = 样本标准差
  Φ(Z)      = 标准正态分布累积函数
```
