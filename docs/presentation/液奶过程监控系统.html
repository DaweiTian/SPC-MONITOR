质量管控前移

从事后检验到过程控制

传统模式下，质量问题往往在产品下线后才被发现，此时已经造成了批量不合格。SPC-MONITOR 通过 SPC 统计过程控制技术，在生产过程中实时监控关键质量指标（脂肪、蛋白质、乳糖等），利用 Nelson 8 条判异规则自动识别过程异常，将质量管控节点从"成品检验"前移到"生产过程"。

具体效果

  • 过程异常实时捕捉，问题发现时间从"班后分析"缩短到分钟级
  • 控制图违规点自动高亮标注，检验人员无需人工判图
  • 过程能力指数 (Cpk) 实时评估，低于阈值自动预警
  • 趋势异常提前识别，在指标越限前发出风险提醒
🤖

预测性质量维护

从被动响应到主动预防

系统内置 ETS、ARIMA 等多种时序预测模型，基于历史质量数据自动预测未来走势，并计算越限概率。当预测到质量指标有较高概率超出规格限时，系统以 CRITICAL 级别发出风险预警，为工艺调整争取宝贵的时间窗口，实现"未越限先预防"。

具体效果

  • 时序预测模型自动择优 (MASE 指标)，无需人工选模
  • 越限概率分为 LOW / MEDIUM / HIGH / CRITICAL 四级
  • CUSUM 漂移检测可识别缓慢的工艺漂移趋势
  • 95% 置信区间量化预测不确定性，辅助决策
  • 检验稳定性数据分析，出现异常时及时提醒

Pain Points

行业痛点

传统液奶生产质量监控面临的六大核心挑战，SPC-MONITOR 逐一攻克。

1

数据采集依赖人工

操作员需定期到仪器前查看数据、手工记录到 Excel 或纸质表格。不仅效率低下，而且容易出现抄录错误、遗漏数据等问题，无法实现全天候不间断监控。

影响：数据完整性 <80%，存在人为误差
2

质量异常发现滞后

质量分析通常在班后或次日进行，当发现指标异常时，不合格品已经批量产出。缺乏实时监控和即时告警机制，问题发现存在数小时的延迟。

影响：批量不合格风险，返工/报废成本高
3

设备数据孤岛

工厂通常配备 FT1、FT120、FTA 等多个品牌型号的乳品分析仪，各仪器数据格式不同、存储方式各异（SQL Server、MDB 文件、独立数据库），无法统一查看和关联分析。

影响：数据碎片化，无法全局分析
4

缺乏过程控制手段

质量管控主要依靠成品检验（终点把关），缺少基于 SPC 统计过程控制的过程能力评估。无法定量衡量生产过程的稳定性和能力水平，只能"检出不合格"而无法"预防不合格"。

影响：被动质量管控，无法预防
5

缺乏预测性分析

完全没有基于历史数据的预测分析能力。工艺参数漂移、设备状态变化等导致的质量趋势恶化，只有在指标越限后才能被发现，无法提前预警和干预。

影响：工艺漂移发现滞后，越限后才知道
6

配置变更困难

产品规格限、告警规则、采集频率等关键参数的调整需要修改数据库记录或配置文件，部分场景甚至需要修改代码重新部署，无法灵活应对生产需求变化。

影响：响应慢，需停机调整

实时监控仪表盘

核心入口

系统主页面，提供液奶生产质量的全局实时视图。顶部 5 大 KPI 指标卡（今日检验量、待处理告警、平均 Cpk、变异系数 CV%、偏移量）一目了然掌握当日质量状况。核心区域展示实时质量趋势图（带 USL/LSL 规格限标线和预测叠加），下方产品 Cpk 矩阵以卡片形式展示当前产品各指标的能力指数，红黄绿色标直观识别。

系统每 30 秒自动轮播 Top 3 产品，每 10 秒切换指标，实现无人值守的全局巡检。采集状态面板实时展示当前采集频率、运行状态、上次/下次采集时间、日成功率和数据源连接状态。

  • 5 大 KPI 指标卡 — 今日检验量、待处理告警、平均 Cpk、CV%、偏移量
  • 实时趋势图 — ECharts 平滑曲线+渐变面积，USL/LSL 标线，预测叠加
  • 产品自动轮播 — 30s 切换产品，10s 切换指标，无人值守巡检
  • Cpk 矩阵 — 卡片网格展示各指标 Cpk，红黄绿色标分级
  • 采集状态面板 — 频率、成功率、数据源连接、手动采集按钮
  • 最新告警表 — 最近 5 条告警，严重级别标签，可点击跳转

SPC 控制图分析

统计核心

基于统计过程控制 (SPC) 理论，提供 I-MR（个体值-移动极差）控制图分析。支持两种分析模式：过程分析模式（分析全部数据）和稳定性分析模式（仅分析基准样/标准样）。系统自动计算 UCL（上控制限）、CL（中心线）、LCL（下控制限），并在图上叠加 USL/LSL 规格限标线。

内置完整 8 条 Nelson 判异规则自动检测引擎，违规数据点在控制图上以红色圆点高亮标注，下方表格详细列出每条违规的规则编号、规则名称、描述和严重级别 (CRITICAL/WARNING/INFO)。顶部 4 大 KPI 卡片展示均值、标准差、违规次数和过程状态（受控/失控/基本受控）。

  • I-MR 控制图 — 个体值图 + 移动极差图，d2=1.128 估算 sigma
  • Nelson 8 条规则 — R1 超 3σ、R2 连续 9 点同侧、R3 连续 6 点单调等
  • 双模式分析 — 过程分析（全部数据）/ 稳定性分析（基准样）
  • 违规高亮 — 红色标注违规点，表格列出规则详情和严重级别
  • 灵活筛选 — 产品/指标/窗口大小 (10-100)/日期范围/备注过滤
  • 预测叠加 — 可在控制图上叠加跨指标预测曲线
📈

过程能力分析

能力评估

量化评估生产过程满足规格要求的能力。系统计算四大核心能力指数：Cp（过程潜力）、Cpk（过程能力，含偏移修正）、Pp（整体过程潜力）、Ppk（整体过程能力），并支持 Ca（偏移系数）计算。Sigma 水平仪表盘以 ECharts Gauge 组件直观展示当前过程的西格玛水平 (1σ~6σ+)，配套显示 PPM 缺陷率和合格率。

直方图+正态曲线叠加展示质量数据的频率分布，USL/LSL 标线清晰标注规格范围。Cpk 历史趋势图追踪能力指数的变化走势，1.33 目标线作为能力达标基准。支持单侧规格限（仅有 USL 或仅有 LSL）的自动检测和计算。

  • 四大指数 — Cp/Cpk/Pp/Ppk，色标分级（绿/黄/红）
  • Sigma 仪表盘 — 0~6+ 西格玛水平，PPM 缺陷率，合格率
  • 直方图 — 频率分布 + 正态曲线叠加，USL/LSL 标线
  • Cpk 趋势 — 历史 Cpk 走势，1.33 目标基准线
  • 单侧规格限 — 自动检测仅有 USL 或 LSL 的场景
  • Ca 偏移系数 — 量化过程中心与规格中心的偏移程度
🤖

智能预测预警

AI 驱动

系统内置多模型预测引擎，支持 ETS（指数平滑）、ARIMA（自回归积分移动平均）、MA（移动平均+线性趋势）三种预测模型，通过 ADF 平稳性检验自动选择最优模型（MASE 指标对比）。预测结果包含点预测值和 95% 置信区间，可视化展示历史数据+预测曲线+置信区间带。

风险监测面板包含四大维度：Cpk 滑动窗口趋势分析、越限概率分析（基于正态分布 CDF 计算，分 LOW/MEDIUM/HIGH/CRITICAL 四级）、CUSUM 漂移检测（按工艺分段）、过程能力综合评估。当越限风险达到 CRITICAL 级别时，系统弹出全屏告警弹窗，强制提醒操作人员关注。

此外，系统还提供指标相关性分析（Pearson 相关系数热力图）、GBDT 特征重要性排序（Top 10 关键因子）、跨指标预测（如从脂肪预测饱和脂肪）等深度分析能力。

  • 多模型择优 — ETS / ARIMA / MA，ADF 检验 + MASE 对比自动选模
  • 95% 置信区间 — 量化预测不确定性，带状可视化展示
  • 越限概率 — 正态分布 CDF 计算，LOW/MEDIUM/HIGH/CRITICAL 四级
  • CUSUM 漂移检测 — 按 HG/换罐 工艺分段，识别缓慢漂移
  • 相关性热力图 — Pearson 相关系数矩阵，揭示指标间关联
  • GBDT 特征重要性 — 梯度提升树排序 Top 10 关键影响因子
  • 跨指标预测 — 线性系数预测，如 saturated_fat = fat × 0.6278
  • 模型评估表 — MASE/MAPE/RMSE/MAE/方向准确率全指标对比
🔔

告警管理中心

实时响应

统一管理所有质量告警事件。告警来源包括 Nelson 规则违规、Cpk 低于阈值、规格限越限三大类，每条告警自动生成唯一编号 (OM-YYYYMMDD-XXXXXX)。告警分为 CRITICAL（严重）、WARNING（警告）、INFO（信息）三级，不同级别在 UI 上以红/橙/蓝色标区分。

系统内置 24 小时去重窗口，相同产品+指标+规则的告警在 24 小时内不重复生成。支持单条和批量处置（确认/作废数据），处置时可添加备注说明。7 天告警趋势图（按日按级别堆叠柱状图）和规则类型分布饼图帮助分析告警模式。WebSocket 实时推送新告警，配合系统通知和声音告警确保及时响应。

  • 三级告警 — CRITICAL/WARNING/INFO，红/橙/蓝色标
  • 24h 去重 — 同产品+指标+规则不重复告警
  • 7 天趋势图 — 按日按级别堆叠柱状图
  • 规则分布饼图 — 各类告警规则占比分析
  • 批量处置 — 勾选多条告警，一键确认或作废数据
  • 实时推送 — WebSocket + 系统通知 + Web Audio 声音
  • 分页浏览 — 按严重级别/状态/产品/关键词筛选
⚙

多源数据采集

数据底座

系统的核心数据底座，无缝对接三类乳品分析仪：FT1（SQL Server 关系型数据库）、FT120（Access MDB 文件）、FTA Perten（独立 SQL Server 数据库）。每种仪器对应独立的采集器实现，共享统一的基类接口（采集、断点续传、规格限、修正值、产品管理）。

自适应采集调度器内置频率梯度 [5, 15, 30, 60, 120, 300] 分钟，在有新数据时保持高频采集（5 分钟），当连续无新数据时自动降频节能，数据恢复时自动提频回到 5 分钟。断点续传机制确保系统重启后不重复采集。修正值系统支持按产品+指标设置校准偏移量，在采集时自动应用。

  • FT1 采集器 — SQL Server 4 表关联结构 (Sample/Product/Component/Prediction)
  • FT120 采集器 — Access MDB 文件解析 (access-parser 库)
  • FTA 采集器 — Perten FTA 数据库 (EstimateEvent/Estimate 表)
  • 自适应调度 — 频率梯度 [5/15/30/60/120/300] 分钟自动调节
  • 断点续传 — 断点文件记录进度，重启不重复采集
  • 修正值系统 — 按产品+指标校准偏移，采集时自动应用

数据管理与配置

运维管理

系统提供 17+ 项运行时配置能力，均支持热更新（无需重启服务）。包括：SQL Server 连接配置（含连接测试、数据库探索、关系型测试）、MDB 文件配置、FTA 数据库配置、采集频率与 SPC 窗口设置、Nelson 规则启用/禁用和严重级别调整、产品状态管理（启用/禁用监控）、规格限配置（USL/LSL/目标值）、修正值配置、产品分类（14 个乳制品分类）、别名配置、排除备注关键词、预测配置等。

数据管理页面提供分页数据浏览、修正值在线编辑、规格限在线调整、数据作废/恢复、CSV 导出等功能。支持按日期范围、产品、指标多维筛选。

  • 仪器切换 — Mock / FT1 / FT120 / FTA 一键切换数据源
  • 规格限配置 — 按产品+指标设置 USL/LSL/目标值
  • Nelson 规则 — 8 条规则独立启用/禁用，严重级别可调
  • 产品管理 — 启用/禁用监控、分类管理、别名设置
  • 数据浏览 — 分页列表，多维筛选，修正值编辑，作废/恢复
  • CSV 导出 — 按筛选条件导出数据用于离线分析

桌面原生应用

Tauri v2

基于 Tauri v2 (Rust) 构建的桌面原生应用，安装包体积 <20MB，内存占用远低于 Electron 方案。提供系统托盘常驻（最小化到托盘不退出）、原生系统通知推送、开机自启动管理、后端进程生命周期管理（自动启动/停止 Python 后端服务）、声音告警（Web Audio API 合成提示音）等原生能力。

  • 系统托盘 — 最小化到托盘，双击恢复窗口
  • 原生通知 — 系统级弹窗通知，不依赖浏览器权限
  • 开机自启 — 可配置的自启动行为
  • 进程管理 — 自动启停后端服务，窗口关闭即退出
  • 声音告警 — Web Audio API 合成提示音，CRITICAL 级别触发

Technology

技术亮点

自研分析引擎、自适应调度、实时推送、桌面原生集成等核心技术能力。

⚖

SPC 分析引擎

完整实现 I-MR 控制图（d2=1.128 估算 sigma，D4=3.267 计算 MR UCL）和全 8 条 Nelson 判异规则。过程能力计算含 Ca 偏移系数，支持单/双侧规格限，PPM 缺陷率基于 scipy.stats.norm 精确计算。

NumPy + SciPy
🔬

预测分析引擎

ADF 平稳性检验自动选择差分阶数，ETS 和 ARIMA 双模型 MASE 对比择优。GBDT 梯度提升树排序特征重要性，Pearson 相关系数矩阵带 p 值检验，越限概率基于正态 CDF 精确计算。

statsmodels + sklearn
⚡

自适应采集调度

频率梯度 [5/15/30/60/120/300] 分钟，基于 BackgroundScheduler 后台运行。连续无新数据时自动降频节能（每级停留一个周期后降级），数据恢复时立即重置到 5 分钟高频采集。

APScheduler
📡

WebSocket 实时推送

FastAPI 原生 WebSocket 支持，定义 6 种消息类型（data_update / new_alert / stats_update / risk_alert / connected / heartbeat），30 秒心跳保活，前端自动重连。

FastAPI WebSocket

Roadmap

下一步规划

分三个阶段持续演进，从能力增强到智能深化，最终打造乳制品智能质量管控标杆平台。

PHASE 1

能力增强与体验优化

在现有功能基础上深化能力、优化体验，覆盖更多分析场景和使用终端。
告警规则引擎升级 支持自定义组合条件和阈值联动，如"Cpk < 1.33 且连续 3 点下降"触发升级告警
SPC 图表扩展 增加 X-bar/R 分组控制图、CUSUM 图、EWMA 图，覆盖更多 SPC 分析需求
PDF 分析报告自动生成 一键生成包含控制图、能力分析、趋势预测的 PDF 质量分析报告
历史数据回溯分析 支持选择历史时间段进行 SPC 和能力分析，对比不同时期的过程表现
PHASE 2

智能分析深化

引入 AI 大模型和高级分析方法，从数据展示升级到智能洞察和自动决策支持。
LLM 自然语言交互 集成大语言模型，支持自然语言查询质量数据（如"最近一周脂肪指标的 Cpk 趋势"）和自动生成分析报告
异常根因分析 基于因果推断算法，自动定位质量异常的工艺环节和可能原因，缩短排查时间
多变量 SPC 分析 引入 T2 Hotelling 控制图和 PCA 主成分分析，支持多指标联合监控
预测模型升级 引入 Prophet / LSTM / Transformer 等深度学习时序模型，提升长周期预测精度
工艺参数关联分析 将温度、压力、流量等工艺参数纳入分析，建立工艺-质量关联模型
智能告警降噪 基于历史处置数据训练模型，自动识别低价值告警并降级，减少告警疲劳
PHASE 3

平台化与生态扩展

从单工厂工具升级为集团级平台，打通上下游系统，构建质量知识生态。
多工厂分布式部署 支持集团级统一管控，多工厂/多产线数据汇聚，总部实时查看各工厂质量状况
质量知识图谱 构建工艺-质量-原料关联知识库，积累和传承质量管控经验
开放 API 平台 提供标准化 RESTful API，与 MES/ERP/LIMS 等上下游系统对接集成
数字孪生 建立液奶生产过程的虚拟仿真模型，支持工艺参数优化的虚拟实验
全链路质量溯源 从原料到成品的全链路质量追溯，支持质量问题的快速定位和召回
质量对标管理 多工厂间质量指标对标分析，识别最佳实践并推广
