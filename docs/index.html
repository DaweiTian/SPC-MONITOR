系统简介

液奶过程监控系统是一套面向乳制品生产过程的实时SPC分析平台，集成FT1数据定时采集、统计过程控制（SPC）分析、过程能力评估、指标趋势预测和分级预警功能，帮助质量管理人员实时掌握生产过程稳定性。

功能模块说明

  • 实时看板：展示今日检测量、预警数、采集状态等关键指标，实时刷新数据趋势
  • SPC控制图：支持I-MR和X-bar R控制图，自动计算控制限，标注Nelson判异规则违规点
  • 过程能力：计算Cp/Cpk/Pp/Ppk，直方图+正态分布曲线，西格玛水平和PPM不合格率
  • 指标预测：基于历史数据的趋势预测，支持移动平均、指数平滑、ARIMA模型
  • 预警中心：分级预警管理，支持确认、处理、关闭全流程，预警趋势分析
  • 数据管理：FT1原始数据浏览、筛选、导出
  • 配置管理：品项、指标、规格限、采集频率、预警规则的可视化配置

技术架构

  • 前端：React + Element Plus + ECharts
  • 后端：Python (FastAPI + NumPy + SciPy + Statsmodels)
  • 启动器：Rust (进程管理 + 系统托盘)
  • 实时通信：WebSocket

SPC判异规则（Nelson Rules）

规则描述异常类型
规则11点超出3σ控制限突发异常
规则2连续9点在中心线同侧均值偏移
规则3连续6点递增或递减趋势异常
规则4连续14点交替上下数据分层
规则5连续3点中2点在2σ外中等偏移
规则6连续5点中4点在1σ外小偏移
规则7连续15点在1σ内数据异常集中
规则8连续8点无1点在1σ内数据过度分散
